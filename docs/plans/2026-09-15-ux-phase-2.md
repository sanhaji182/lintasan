# UX Phase 2 Workflow Consolidation Implementation Plan

> **For Hermes:** Implement task-by-task with strict RED → GREEN verification and checkpoint commits.

**Goal:** Make callable models discoverable, model selection scalable, and operator workflows explicit without changing gateway behavior or mutating live routes during QA.

**Architecture:** Add pure TypeScript catalog/combobox derivation utilities shared by a new Models page and Playground. Keep existing APIs as sources of truth, represent unavailable metadata as “Not reported”, and leave all routing mutations behind explicit scoped save actions. Connections remains the existing feature-rich page but defaults to compact provider summaries and makes bulk/add modes explicit. Observability labels distinguish retained snapshots, process-lifetime counters, and SSE transport freshness.

**Tech Stack:** Svelte 5/SvelteKit static SPA, TypeScript pure helpers tested with Node test runner, existing Go HTTP contracts.

---

### Task 1: Canonical model inventory
- Test: add failing behavioral tests for dedupe, grouping, health, unknown metadata, fuzzy filtering, and recent selection.
- Implement `frontend/src/lib/model-catalog.ts` and `/dashboard/models` using `/v1/models`, `/api/combos`, `/api/aliases`, and `/api/connections`.
- Add Models to Gateway navigation and page titles.
- Verify focused test, frontend check/build, checkpoint commit.

### Task 2: Accessible Playground model combobox
- Extend failing tests for grouping, recent/recommended ordering, and persistence rules.
- Replace native select with an ARIA combobox/listbox supporting search, arrow keys, Enter, Escape, metadata, and localStorage last/recent model IDs.
- Preserve query-param selection and cloud-agent non-streaming behavior.
- Verify and checkpoint commit.

### Task 3: Connections density and actions
- Add source-level behavioral assertions for compact-by-default groups, sticky filters, explicit bulk mode, and one contextual Add menu.
- Preserve all existing provider/account actions and Hoplite virtual dispatch.
- Verify and checkpoint commit.

### Task 4: Routing save scopes
- Add pure dirty-state helpers and failing tests.
- Split page into Policies, Combos, and Quotas views. Stage policy/combo edits locally; provide explicit scoped Save/Discard with dirty feedback. Preserve priority-only Cloud Agent validation.
- Verify and checkpoint commit.

### Task 5: Observability truthfulness
- Add tests for scope/freshness wording and reconciliation behavior.
- Label analytics snapshot vs global counters, expose retrieved-at freshness, and explain totals when retained logs differ from global request counts.
- Verify and checkpoint commit.

### Task 6: Full verification and release
- Run frontend behavioral tests, `svelte-check`, frontend build, full Go tests, and diff/security review.
- Push checkpoint commits, run safe `make build`, deploy with automatic binary backup, and verify health/version, auth boundaries, page reachability, console, desktop/mobile, and read-only API behavior.
- Record rollback backup and block for independent review.
